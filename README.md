# Taejun Ha — Academic Homepage

A clean, responsive, single-page academic website based on the supplied October 2026 LaTeX CV.

## Preview locally

Open `index.html` in any modern browser. No installation, server, framework, or account is required.

## Publish for free with GitHub Pages

1. Create a public GitHub repository named `TaeJun1999.github.io` in the GitHub account `TaeJun1999` (or your own username followed by `.github.io`).
2. Upload **the contents of this folder** to the repository root, including `index.html`, `favicon.svg`, and the `assets` folder.
3. In the repository's **Settings → Pages**, select the deployment source **Deploy from a branch**, branch **main**, folder **/(root)**, then save. If it is already configured, leave it as is.
4. Once publishing is complete, open `https://taejun1999.github.io` (or the address corresponding to your GitHub username).

GitHub may take a short time to publish changes. A custom domain is optional and may cost money; GitHub Pages hosting for an eligible public repository is free.

## Edit content

- `index.html` contains the complete design and page content. Edit it with any text editor.
- Update paper statuses, links, affiliations, and dates when they change.
- `assets/Taejun_Ha_CV_public.pdf` is the **public** CV linked from the website.
- `assets/Taejun_Ha_CV_public.tex` is the editable LaTeX source for that public PDF.
- To replace the PDF, compile the TeX source and keep the PDF filename identical, or update the links in `index.html`.

## Public-information choices

The public CV is adapted from the uploaded CV. Phone numbers, GPAs, military-service detail, and TOEFL scores were intentionally omitted from the public PDF. The homepage likewise omits those fields. Please review all public content before publishing.

Paper status labels follow the submitted CV as of October 2026 and have not been externally verified. Paper links are supplied only where a URL was present in the source CV. No backend or tracking script is used.
